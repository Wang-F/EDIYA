## 图片建议
- 尺寸：建议 800x800 像素或更大
- 格式：JPG 或 WebP
- 背景：建议使用纯色或透明背景
- 风格：高端、时尚、专业的产品摄影风格

## 图片来源建议
1. 自己拍摄产品照片
2. 使用 Unsplash、Pexels 等免费图库搜索 "sunglasses"
3. 购买商业图库素材
